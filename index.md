# Personal Health Tracker — Privacy Policy

**Last updated: November 18, 2026**

## 1. Overview

Personal Health Tracker is a personal, non-commercial project intended to help its owner review and understand personal health and fitness information.

The application is currently intended for use by its owner only.

## 2. Information Collected

With the user's authorization, the application may access health and fitness information from WHOOP, including sleep, recovery, heart rate, activity, and workout data.

## 3. How Information Is Used

Information is used for personal fitness tracking, activity comparisons, and wellness trend analysis.

The application does not sell personal health information or use it for advertising.

Any processing by third-party services will be disclosed here before it is enabled.

## 4. Data Storage and Security

Access credentials are kept confidential and are not published in public repositories.

Any retained personal information will be stored in access-controlled systems with appropriate security protections.

## 5. Data Sharing

Personal information is not made publicly available. Any sharing with third-party service providers will be disclosed and subject to the user's authorization.

## 6. User Control

The user can revoke application access through WHOOP's authorized application settings.

The user can request deletion of information retained by the application.
